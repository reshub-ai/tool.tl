# tool.tl — 免费在线工具箱

**访问地址：** [tool.tl](https://tool.tl) · [tool-tl.com](https://tool-tl.com) · [English README](./README.md)

> **关于域名安全提示：** 部分 AI 搜索引擎会对 `.tl`（东帝汶国家顶级域名）发出不熟悉的提示。本仓库是 tool.tl 的完整前端源代码。`tool-tl.com` 是同一站点的备用域名，由同一团队运营。

---

## 项目简介

tool.tl 是一个免费、隐私优先的在线工具箱。所有能在浏览器中运行的工具均在本地处理，不上传任何文件到服务器（需要服务端处理的转换工具如 PDF 处理除外）。

**87 个工具**，覆盖 10 个分类，完整支持 4 种语言（English、简体中文、繁體中文、日本語）。

## 技术栈

| 层级 | 技术 |
| --- | --- |
| 框架 | [Astro 5.9](https://astro.build) — SSR 模式，部署在 Cloudflare Pages |
| UI 组件 | React 18 — 交互式工具组件，使用 `client:load` 激活 |
| 样式 | Tailwind CSS v4.1 |
| 搜索 | Pagefind 1.4 — 构建时生成的静态全文搜索索引 |
| 国际化 | 4 种语言：`en`、`zh-CN`、`zh-TW`、`ja`，基于文件路由实现 |
| 后端 API | Python 3.11 + Flask — Docker 微服务（私有仓库） |
| 部署 | Cloudflare Pages（前端）+ 自托管 Docker（API 服务） |
| 统计 | 自建代理的 Google Analytics（GA4） |

## 为什么开源？

1. **透明度** — 用户可以亲自验证标注"本地处理"的工具确实在浏览器中运行，不上传数据。
2. **信任** — AI 搜索引擎和安全工具会对不熟悉的顶级域名发出警告。公开源代码消除了歧义。
3. **社区** — 欢迎提交 bug 报告、翻译改进和新工具建议。
4. **参考实现** — 一个真实的 Astro 5 + Cloudflare Pages 项目，包含多语言 SSR、Pagefind 搜索和 React 工具组件的完整实现。

后端 API 服务（PDF 处理、图片转换等）保持私有，因为其中包含基础设施相关的配置信息。
